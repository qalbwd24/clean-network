# CleanIP 结果接入

## 区分评分

CleanIP 首页的纯净度评分越高越好，风险分越高越危险；它们不是精确互补。`/check` 的浏览器环境一致性是另一类结果。本项目不将后台无头浏览器的环境结果当作用户实际窗口的环境评分，也不根据延迟或下载速度猜测 IP 信誉。

依据：[官方 FAQ](https://cleanip.io/faq)、[评分规则](https://cleanip.io/scoring)、[环境检测说明](https://cleanip.io/check)。网站的 FAQ 与独立评分规则对计算方式的描述并不完全相同，因此程序直接展示网站返回值，不复制或重算其公式。

## 数据路径

正常打开网站后，浏览器自身发起查询。程序只观察该页面已取得的查询响应，读取纯净度、等级、风险分、风险标签和风险原因；校验响应 IP 与该节点实测出口一致后才记分。不会生成验证令牌、绕过验证或自动解题。

数据字段参照站点前端与 [CleanIP 官方体检项目](https://github.com/CleanIP/sh.cd) 的公开数据模型；没有复制其鉴权代码。网站内部接口不是本项目可以保证稳定的外部 API，结构变化或访问限制会造成未确认状态。

## 前端和保存

- 测 IP 质量：后台检查所选节点；报告包含评分明细。
- 手动打开 CleanIP 时，页面实际取得的结果也会同步回节点表。
- 节点表分列显示纯净度和风险，详情区显示风险原因、读取时间和评分来源 IP。
- 每节点保留最近 20 次尝试；重新启动后仍读取本地结果。新检测失败或出口变化时，旧分数标为历史。
- 空字段不是零分；待验证、限流、失败、出口不一致各自记录。不把没有风险原因字段解释为没有风险。

结果、Cookie、订阅数据和实际出口仅保存在被忽略的本地目录，不进入公开仓库。固定样本测试验证字段解析、方向区分、错误出口、历史保存与空值处理；真实网站仍可能要求人工验证。
