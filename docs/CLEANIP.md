# CleanIP 结果接入

## 区分评分

CleanIP 首页的纯净度评分越高越好，风险分越高越危险；它们不是精确互补。`/check` 的浏览器环境一致性是另一类结果。本项目不将后台无头浏览器的环境结果当作用户实际窗口的环境评分，也不根据延迟或下载速度猜测 IP 信誉。

依据：[官方 FAQ](https://cleanip.io/faq)、[评分规则](https://cleanip.io/scoring)、[环境检测说明](https://cleanip.io/check)。网站的 FAQ 与独立评分规则对计算方式的描述并不完全相同，因此程序直接展示网站返回值，不复制或重算其公式。

## 数据路径

正常打开网站后，浏览器自身发起查询。程序只观察该页面已取得的查询响应，读取纯净度、等级、风险分、风险标签和风险原因；普通指定 IP 查询须与该节点实测出口一致。快捷查询若观察到网站自身的 `/api/v2/me` 正常响应，则以该响应的出口 IP 作为 CleanIP 评分来源；如与连通查询的出口不同会明确标记，不将这一规则用于指定任意 IP 的查询。不会生成验证令牌、绕过验证或自动解题。

数据字段参照站点前端与 [CleanIP 官方体检项目](https://github.com/CleanIP/sh.cd) 的公开数据模型；没有复制其鉴权代码。网站内部接口不是本项目可以保证稳定的外部 API，结构变化或访问限制会造成未确认状态。

## 前端和保存

- 测 IP 质量：后台检查所选节点；报告包含评分明细。
- 手动打开 CleanIP 时，页面实际取得的结果也会同步回节点表。
- 节点表分列显示纯净度和风险，详情区显示风险原因、读取时间和评分来源 IP。
- 每节点保留最近 20 次尝试；重新启动后仍读取本地结果。新检测失败或出口变化时，旧分数标为历史。
- 空字段不是零分；待验证、限流、失败、出口不一致各自记录。不把没有风险原因字段解释为没有风险。

结果、Cookie、订阅数据和实际出口仅保存在被忽略的本地目录，不进入公开仓库。固定样本测试验证字段解析、方向区分、错误出口、历史保存与空值处理；真实网站仍可能要求人工验证。

## 首页快捷查询（收藏更新）

“查询所选节点”与“查询收藏”读取正常页面已返回的结果，额外保存 `radar.human_pct` / `radar.bot_pct`，保留小数及有效的 0%，缺失字段显示未获取。它们是所属 ASN 的统计，不是用户自己的流量。

IP 风险项直接读取网站已渲染的风险矩阵状态（clear/hit/unknown），排除连接与浏览器环境行；来源不完整或存在冲突时保持未知。完整、全部通过且没有额外风险提示才显示全过，范围与更新时间一起展示。页面尚未生成风险矩阵时不会根据高分或空风险字段推断全过。

上传下载通过当前独立节点访问 Cloudflare 官方测速端点（[接口说明](https://github.com/cloudflare/speedtest)）。每方向最多 10 MB、数据阶段约 4 秒；下载以实际收到字节和传输耗时计算，上传按已收到成功响应的样本总字节除以这些样本的总耗时，包含请求往返开销。测速过程中显示本次平均值；它是本次短时 HTTP 传输的观测值，并非带宽套餐上限。

所有快捷查询结果仍保存在本地 results.json，重新查询失败时评分与人机比例明确标为历史。验证码由用户在正常网页中完成，程序不自动解题或绕过验证。
