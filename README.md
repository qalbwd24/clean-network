# 纯净网络检测工具

<img src="assets/app.png" width="80" alt="纯净网络图标">

Windows 节点检测工作台：读取 Clash 当前节点，测试延迟和下载速度，生成本地质量报告，或打开各自固定出口的 Chrome 窗口。

## 功能

- 自动读取 Clash Verge 当前生成的配置，跟随订阅更新；也可指定其他 Clash YAML 文件。
- 单个、所选或全部节点测延迟，最多六路并发；延迟测试网址可配置。
- 下载测速使用独立通道，不切换正在浏览的节点；多个节点依次测试，避免互相争抢带宽。
- 生成检测报告：后台测试网络、查询出口、访问所选网站，保存汇总表、评分摘录和网页截图，不弹出测试窗口。
- 前端分列显示 CleanIP 纯净度与风险分，选中节点可看风险原因、评分来源 IP 和读取时间；保留最近 20 次尝试，失败或出口变化时标记历史值。
- 手动检测最多同时打开四个独立节点窗口，标题与页面角标都显示节点；各窗口有独立浏览器环境和固定出口。
- 自定义检测网站，深浅色主题，9–22pt 字号、Ctrl 加滚轮调整、托盘和单实例唤回。
- 可选开机自启：等待 Clash 通过代理连通检查后，再检查当前出口。

网站评分只展示实际读到的文本摘录。人机验证、访问失败和未识别评分会分别标记，不把打开或截图成功当作评分通过。网络评价依据当前测试：超过 1000ms 标记延迟偏高，已测下载低于 3Mbps 标记下载偏慢；它不代表 IP 信誉或长期稳定性。

## 构建和启动

需要 Windows、.NET Framework 4.8、Chrome；构建另需 Node.js 和系统 C# 编译器。程序运行不依赖 Node、Python 或 PowerShell。

1. 从 [Mihomo 官方 Releases](https://github.com/MetaCubeX/mihomo/releases) 获取适合系统的 Windows 内核，解压并将其命名为 `mihomo.exe`，放到 `assets/bin/`。仓库不附带第三方内核二进制。
2. 在项目目录运行 `构建.cmd`，生成 `CleanNetwork.exe`。
3. 双击 EXE。首次读取 Clash Verge；没有读到时，在设置中选择节点 YAML 文件。节点配置留空即自动跟随 Clash Verge。

构建脚本使用项目相对路径和 Windows 环境目录，无需修改个人路径。图标的 SVG、PNG、ICO 已包含；可用系统 C# 编译器编译 `src/tools/MakeIcon.cs` 后重新生成，不影响普通构建。

## 检测报告

选中或勾选节点、勾选检测站点，点击生成检测报告。包含下载测速时，每节点最多下载 10 MB、约四秒；可取消勾选。大量节点会先显示流量上限。后台依次检测，可随时停止，已完成部分保留。

完成后点击查看报告。HTML 汇总表按连通结果和延迟排列，逐站显示评分摘录、未确认项与截图，也可打印为 PDF。报告与 JSON 明细在 `outputs/reports/`；停止或部分网站失败也会保留结果。

测 IP 质量按钮单独检查 CleanIP，不下载测速。手动窗口正常取得的 CleanIP 查询结果也会同步回表格。它读取正常页面已有的响应，不生成验证令牌、不自动解题；站点限制或响应结构变化时会标记未确认。接入说明和评分方向见 [CleanIP 结果接入](docs/CLEANIP.md)。

手动打开节点窗口用于复核。再次打开同一节点会复用其独立环境；已打开节点不随其他窗口或报告通道切换。关闭所选窗口只关闭对应节点。

## 订阅和开机检查

节点表来自当前配置中的 `proxies` 与 `proxy-providers`，不是固定列表。订阅更新后保留仍存在节点的测试结果。若有手动测试窗口正在使用旧配置，会先提示，待这些窗口关闭后再应用新节点，防止出口在查看时变化。

开机自启可在设置里启用或关闭。启动项只作用于当前 Windows 用户；启动后等待 Clash 的代理端口和联网检查，最长三分钟，再记录当前出口并通知。不会自动打开一批浏览器或进行批量下载测速。

## 本地数据

| 路径 | 内容 |
|---|---|
| `src/` | C# 源码和构建脚本 |
| `assets/` | 界面、节点角标脚本和图标 |
| `data/` | 设置、结果、私有代理配置、浏览器环境 |
| `outputs/reports/` | 本地检测报告和导出 |
| `tmp/`、`logs/` | 临时文件和本地日志 |

`data/`、`outputs/`、`tmp/`、`logs/` 均不纳入版本控制。浏览器环境可能包含 Cookie，代理配置可能包含订阅凭据，报告可能包含出口信息，不能作为公开示例上传。

程序只读取原 Clash 配置，不修改系统代理、DNS、TUN 或共享节点选择。独立内核和调试端口只监听本机回环。时区仅设置到测试页面，不修改 Windows 时区。

## 测试与第三方组件

`CleanNetwork.exe --self-test` 验证配置提取、订阅切换、网址限制、设置持久化、报告解析与转义、图标和布局。网络集成测试需显式选择可用节点，产生的报告保留在本机。使用测试入口时建议通过 `--data-root` 指向隔离目录。

代理功能使用 [Mihomo](https://github.com/MetaCubeX/mihomo)，浏览器控制使用 [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/)。第三方组件按其各自许可使用；Chrome 使用用户已有的安装。
